# Magic Survival 技能查找工具 規格書

## 1. 系統定位
* 運行環境：靜態網頁
* 介面設計：行動裝置優先
* 資料來源：本地 JSON 檔案
* 狀態儲存：瀏覽器 LocalStorage

## 2. 功能清單

### 2.1 資料檢視
* 總覽列表：預設陳列所有融合技能。清單卡片需明確顯示：融合技能名稱、主技能（含附魔）、副技能（含附魔），若有對應的「終極技能」、「學派」、「實驗體」，需以標籤（Tag）或圖示呈現。
* 主副標示：視覺上區分主技能保留與副技能消耗。
* 頂置顯示：可將常用融合技能頂置，於圖鑑列表優先顯示（Local Storage 記憶）。頂置僅影響排序：不做衝突檢測、無數量上限、仍遵循搜尋與篩選條件。頂置之間可用上下按鈕調整順序；篩選中調整時以畫面上可見的鄰居為交換對象。列表上方顯示頂置數量與「全部解除」按鈕（直接執行，可由提示訊息復原）。

### 2.2 搜尋與篩選
* 關鍵字搜尋：透過文字輸入框尋找融合技能名稱。
* 技能反查：選擇單一基礎技能，列出相關的融合技能。
* 精準反查：採用連動式下拉選單（先選擇基礎技能，第二選單自動列出對應的附魔供選擇），精準列出對應的融合技能。
* 學派過濾：選擇特定職業學派後，清單僅顯示「該學派專屬技能」與「無限制的通用技能」，隱藏其他學派專屬的技能。
* 實驗體篩選：選擇特定實驗體，過濾出該實驗體專屬的融合技能組合。

### 2.3 玩家建構模擬
* 我的最愛：點擊按鈕將特定融合技能加入自訂清單（Local Storage）。
* 衝突檢測：系統自動檢查最愛清單。若多個融合技能使用到相同的基礎魔法（不論是作為主技能或副技能），因遊戲機制無法同時存在，介面需顯示紅色警告。
* 上限提示：若清單內選擇的融合技能超過遊戲常規數量上限（如 3 個），介面給予視覺上的溫馨提醒。
* 清單排序：允許使用者以拖曳或按鈕調整最愛清單內的技能順序。
* 一鍵清空：提供一鍵清空所有最愛項目的功能，方便玩家重新配裝。
* 建構匯出：允許將目前的最愛清單內容轉換為易讀的純文字格式，方便玩家複製分享給其他人。

### 2.4 體驗優化
* 深色模式：支援深淺色背景切換，預設套用系統設定。
* 觸控優化：元件尺寸符合手機操作標準。
* 視覺回饋：操作（如加入最愛、清空、發生衝突）發生狀態改變時顯示提示訊息。
